## 1. 프로젝트 개요

- 목적: 일반 블로그를 홈페이지형 전문 블로그로 리뉴얼하여 신뢰감 형성 및 견적 유도
- 타겟 고객: 시공사·시행사, 빌라/상가 건물주, 주차장 사업 관계자
- 핵심 경쟁력: 전국 직영 시공, 1년 무상 A/S, 특허 차량번호인식 기술, 국내 생산 제품
- 디자인 방향: Apple.com 계열의 모던 미니멀 디자인. v1.2에서 라이트 모드(화이트 메인 배경)로 확정

## 2. 메인 화면 및 브랜딩

### F-MAIN-1. 홈페이지형 메인 화면

- 고해상도 실물 현장 사진을 라운드 24px 히어로 영역의 배경으로 사용
- 하단으로 갈수록 흰색이 짙어지는 그라디언트 오버레이로 라이트 테마와 자연스럽게 결합
- 좌측에 큰 볼드 헤드라인(SF Pro 계열, 좁은 자간)으로 캐치프레이즈 노출
- 하단에 핵심 바로가기 필(pill) 버튼 4개 배치. 첫 번째 버튼만 차콜 배경으로 강조
- PC/모바일 모두 최적화

### F-MAIN-2. 신뢰감 브랜딩

- 화이트(#FFFFFF) 메인 배경 + 차콜(#1D1D1F) 텍스트의 라이트 모노톤 디자인
- 푸터에 사업자정보 + 네이버지도 삽입, 보조 텍스트 컬러(#6E6E73) 사용
- 위젯 연동 (전화, 카카오톡, 견적문의) — 필 버튼 컴포넌트로 통일

### F-TRUST-1. 신뢰 지표 스트립 (v1.2 신규)

- 핵심 경쟁력 4가지를 히어로 바로 아래에 요약 노출
- 항목: 전국 직영 시공 / 무상 A/S 1년 / 특허 LPR 카메라 / 국내 생산 직거래
- 각 칸은 제목 + 한 줄 설명 구성. 라운드 18px 스트립 안에 1px 헤어라인으로 분할
- PC 4열 / 모바일 2열로 반응형 전환

## 3. 디자인 시스템 (v1.2 개정)

클라이언트 승인 시안(luce_company_blog_design.html) 기준입니다.

### F-DESIGN-1. 비주얼 디자인 시스템

- 컬러: 화이트(#FFFFFF) 메인 배경, 텍스트 #1D1D1F, 서브 배경 #F5F5F7, 카드 배경 #FBFBFD, 보조텍스트 #6E6E73, 헤어라인 #D2D2D7
- v1.1의 포인트 블루(#2997FF)는 사용하지 않음. 강조는 차콜 필 버튼으로 대체
- 타이포그래피: 시스템 폰트(-apple-system / San Francisco), 헤드라인 굵게 + 좁은 자간
- 컴포넌트: 라운드 카드(18px, 시공사례 게시물), 필 버튼(980px, CTA/입력창), 1px 헤어라인 구분선
- 레이아웃: 콘텐츠 최대 폭 1040px, 좌우 여백 24px
- 톤앤보이스: 절제된 여백, 과한 그림자·그라데이션 배제, 사진과 타이포그래피 중심

### F-DESIGN-2. 게시물 카드 컴포넌트

- 카테고리 라벨 + 제목 + 날짜의 3단 구성 카드
- 시공 사례 카테고리에 적용. 그리드 레이아웃(PC 3열 / 모바일 1열)으로 노출
- v1.2에서 주차장 상식은 카드가 아닌 리스트형 행을 사용 (F-KNOW-1 참조)

## 4. 콘텐츠 카테고리

### F-PORT-1. 시공 사례 (PORTFOLIO)

- 빌라/오피스텔, 상가/빌딩, 주차 유료화/무인화
- 전후 사진, 작동 영상, 후기 포함
- F-DESIGN-2 카드 컴포넌트로 목록 노출

### F-KNOW-1. 주차장 상식 (KNOWLEDGE)

- 차단기 자가정비/팁, 주차장 법규/설치 기준
- v1.2 변경: 카드 그리드 대신 제목 + 날짜의 리스트형 행으로 노출. 정보성 콘텐츠 특성상 목록 훑기가 쉽도록 밀도를 높임
- 각 행은 1px 헤어라인으로 구분

### F-INQ-1. 상담 및 문의 (INQUIRY)

- 간편 견적 문의 — 서브 배경 밴드(#F5F5F7) + 필 버튼 입력 폼으로 노출
- 공지사항

## 5. 기술/운영 요구사항

### F-UI-1. 모바일 최적화

- 모바일 상단에 직통 전화번호 상시 노출. 라이트 테마 화면에서 눈에 띄도록 차콜 배경 바로 처리
- 라이트 테마 동일 적용

### F-SEO-1. 검색 최적화

- 프로필, 태그, 메타 설명 최적화

### F-TECH-1. 산출물 단계 분리 (v1.2 개정)

- 1단계: 디자인 확정용 시안 프리뷰 웹페이지 제작 (완료)
- 2단계: 네이버 블로그 홈페이지형 스킨 제작 및 적용 (라이트 테마 기준)
- 네이버 블로그는 레이아웃 폭과 위젯 규격이 고정되어 있어, 1단계 프리뷰를 그대로 이식할 수 없음. 2단계에서 규격에 맞춰 재구성함
