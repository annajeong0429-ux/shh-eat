## 1. 디자인 시스템

luce_company_blog_design.html 기준입니다.

### T-DESIGN-1. 컬러 토큰 (v1.2 개정)

입력: 컬러 팔레트 값 (아래 표)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| background | #FFFFFF | 메인 배경 |
| foreground | #1D1D1F | 본문/헤드라인, 주요 CTA 배경 |
| gray-bg | #F5F5F7 | 문의/구독 밴드 배경 |
| gray-card | #FBFBFD | 게시물 카드 배경 |
| gray-text | #6E6E73 | 보조 텍스트 |
| gray-line | #D2D2D7 | 헤어라인 구분선 |

출력/노출: 전체 화면(PC+모바일)에 동일 토큰 적용. 사진 위 텍스트 영역은 화이트 그라디언트 오버레이 처리

성공요건:

- 전 페이지에서 배경/텍스트 대비가 WCAG AA(4.5:1) 이상 확보된다. 본문 #1D1D1F는 약 16:1, 보조 텍스트 #6E6E73는 약 5.1:1로 기준을 충족한다
- 네이버 블로그 스킨 적용 단계에서 에디터 제약(CSS 적용 범위) 내에 컬러 토큰이 깨지지 않고 렌더링된다

### T-DESIGN-2. 타이포그래피 & 컴포넌트

입력: 폰트 스택(-apple-system 등), 컴포넌트 스펙(카드 18px, 히어로 24px, 버튼 980px, 헤어라인 1px), 콘텐츠 폭 1040px

출력/노출: 헤드라인/본문/캡션 위계, 라운드 카드형 게시물 리스트, 필(pill) 버튼·입력창

성공요건:

- PC/모바일 각 기기 네이티브 시스템 폰트로 정상 렌더링된다 (웹폰트 미탑재 환경 포함)
- 카드·버튼 컴포넌트가 모든 브라우저(네이버 인앱 브라우저 포함)에서 라운드 처리·정렬이 깨지지 않는다
- 히어로 헤드라인이 PC 42px, 모바일 32px로 전환된다

## 2. 메인 화면 및 브랜딩

### T-MAIN-1. 홈페이지형 메인 화면

입력: 배경 이미지, 캐치프레이즈 텍스트, 버튼 링크

출력/노출: 라운드 24px 히어로 영역의 현장 사진(화이트 그라디언트 오버레이 적용), 캐치프레이즈, 4개 필 버튼

성공요건:

- PC와 모바일에서 모두 자연스럽게 표시된다. 히어로 최소 높이 520px을 유지한다
- 버튼 클릭 시 해당 카테고리나 외부 링크(전화, 문의폼)로 정상 이동한다
- 모바일에서는 상단에 직통 전화번호가 항상 노출된다
- 밝은 배경 위 현장 사진의 인물·차량·설비가 오버레이로 인해 과도하게 흐려지지 않는다

### T-MAIN-2. 신뢰감 브랜딩 요소

입력: 컬러 팔레트(T-DESIGN-1 토큰), 푸터 정보

출력/노출: 전체 라이트 톤앤매너, 푸터 사업자정보 + 지도

성공요건:

- 전체적으로 전문적이고 신뢰감 있는 느낌을 준다
- 사업자정보가 법적으로 요구되는 항목을 모두 포함한다
- 푸터 라이트 배경 위 지도 위젯(네이버 지도)의 대비/가독성이 확보된다

### T-TRUST-1. 신뢰 지표 스트립 (v1.2 신규)

입력: 핵심 경쟁력 4개 항목의 제목과 한 줄 설명

출력/노출: 라운드 18px 스트립 안에 1px 헤어라인으로 분할된 4칸 구성

성공요건:

- PC 4열 / 모바일 2열로 반응형 전환된다
- 칸 사이 구분선이 모든 해상도에서 1px로 균일하게 렌더링된다

## 3. 콘텐츠 카테고리

### T-PORT-1. 시공 사례 포트폴리오

입력: 카테고리별 게시물 (사진, 영상, 텍스트)

출력/노출: T-DESIGN-2 카드 컴포넌트로 유형별 분류된 시공 사례 목록

성공요건:

- 고객이 본인 상황(빌라/상가 등)에 쉽게 대입할 수 있다
- 사진과 영상이 정상적으로 노출된다
- 카드 그리드가 PC 3열 / 모바일 1열로 반응형 전환된다

### T-KNOW-1. 주차장 상식 (v1.2 개정)

입력: 정보성 게시물

출력/노출: 제목 + 날짜의 리스트형 행. 각 행은 1px 헤어라인으로 구분

성공요건:

- 포털 검색에서 잘 노출될 수 있도록 키워드 최적화가 적용된다
- 모바일에서 제목이 길어져도 날짜와 겹치지 않고 줄바꿈 처리된다

### T-INQ-1. 상담 및 문의

입력: 견적 문의 폼 데이터

출력/노출: 문의 채널(폼, 카톡, 전화) — 서브 배경 밴드 + 필 버튼/입력창

성공요건:

- 방문자가 2클릭 이내에 문의할 수 있다
- 입력창 텍스트·플레이스홀더가 밝은 배경에서 명확히 구분된다. 입력창은 화이트 배경 + 1px 보더로 밴드 배경과 분리한다

## 4. 기술 요구사항

### T-UI-1. 모바일 최적화

성공요건:

- 모바일에서 번호 터치 시 바로 전화 연결된다
- 상단 전화번호 바가 스크롤 시에도 고정 노출된다

### T-SEO-1. 기본 SEO 세팅

성공요건:

- 프로필, 태그, 설명이 검색 상위 노출에 유리하게 설정된다

### T-TECH-1. 산출물 단계 분리 (v1.2 개정)

1단계 — 디자인 시안 프리뷰

- 출력: 독립 웹페이지 (메인, 시공 사례, 주차장 상식, 상담 및 문의)
- 성공요건: 클라이언트가 실제 동작하는 화면으로 PC/모바일 디자인을 검수할 수 있다

2단계 — 네이버 블로그 스킨 적용

- 출력: 네이버 블로그 홈페이지형 스킨 (PC + 모바일)
- 성공요건: 스킨이 PC/모바일 모두 정상 적용되고, 모든 위젯이 동작한다
- 제약: 네이버 블로그는 레이아웃 폭과 위젯 규격이 고정되어 있고 외부 스크립트를 사용할 수 없다. 1단계 프리뷰의 조판을 그대로 이식할 수 없으므로, 히어로는 이미지와 링크 영역으로, 바로가기 버튼은 위젯으로 재구성한다
