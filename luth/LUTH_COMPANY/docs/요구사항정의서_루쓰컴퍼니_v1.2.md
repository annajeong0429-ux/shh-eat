## 3. 디자인 및 레이아웃 요구사항

### 3-1. 디자인 컨셉 (v1.2 확정)

Apple.com 계열의 모던 미니멀 디자인 기조는 유지하되, 다크 모드가 아닌 라이트 모드로 확정합니다. v1.1에서 확정했던 블랙 메인 배경은 화면 전체가 어둡게 눌리는 인상을 준다는 클라이언트 의견에 따라 철회합니다.

화이트 배경 위에 차콜 텍스트와 연회색 카드를 조합하여, 밝고 정돈된 인상을 주면서도 절제된 여백과 타이포그래피 중심의 톤앤매너는 그대로 유지합니다.

### 3-2. 컬러 팔레트 (v1.2 개정)

| 역할 | 값 | 용도 |
| --- | --- | --- |
| 메인 배경 | #FFFFFF | 전체 페이지 배경 |
| 기본 텍스트 | #1D1D1F | 본문 및 헤드라인 텍스트, 주요 CTA 버튼 배경 |
| 서브 배경 | #F5F5F7 | 섹션 구분 배경(견적 문의 밴드 등) |
| 카드 배경 | #FBFBFD | 시공사례 카드, 신뢰 지표 스트립 |
| 보조 텍스트 | #6E6E73 | 날짜, 카테고리, 캡션 등 2차 정보 |
| 구분선 | #D2D2D7 | 헤어라인 1px 구분선, 카드 보더 |

v1.1의 포인트 컬러(#2997FF)는 사용하지 않습니다. 강조가 필요한 CTA는 차콜(#1D1D1F) 배경의 필 버튼으로 처리합니다.

### 3-3. 타이포그래피 & 컴포넌트

- 폰트: 시스템 폰트 우선 적용(-apple-system / SF Pro Display 계열), 대체 웹폰트 없이 각 기기 네이티브 폰트로 렌더링
- 자간: 본문 기본 -0.011em, 헤드라인 -0.02em으로 타이트하게 조판
- 헤드라인: 굵은 두께(600) 적용. 히어로 42px, 섹션 제목 26px 기준
- 버튼·입력창: 필(pill) 형태 border-radius 980px. 주요 CTA는 차콜 배경, 보조 CTA는 화이트 배경 + 1px 보더
- 게시물 카드: 라운드 코너 18px, 헤어라인 보더, 카테고리 라벨 + 제목 + 날짜 3단 구성
- 구분선: 1px 헤어라인(#D2D2D7)만 사용, 그림자·그라데이션 사용하지 않음
- 콘텐츠 최대 폭: 1040px (좌우 여백 24px)

### 3-4. 메인 화면 (PC) 구성

- 상단 헤더: 로고 + 태그라인, 우측에 4개 메뉴(회사 소개 / 시공 사례 / 주차장 상식 / 견적 문의)
- 히어로: 고해상도 차량 차단기 설치 실물 현장 사진을 라운드 24px 카드형 영역에 배치. 최소 높이 520px
- 히어로 오버레이: 하단으로 갈수록 흰색이 짙어지는 그라디언트를 적용해 텍스트 대비를 WCAG AA 이상으로 확보
- 캐치프레이즈: 좌측 정렬. "확실한 차량 통제의 시작, 간편한 주차시스템을 제안합니다."
- 히어로 하단 핵심 바로가기 버튼 4개: 회사 소개(차콜) / 빌라·상가 시공사례 / 원격 견적문의 / 전화 상담
- 신뢰 지표 스트립: 전국 직영 시공 / 무상 A/S 1년 / 특허 LPR 카메라 / 국내 생산 직거래 4칸 구성
- 시공 사례: 카드 3열 그리드
- 주차장 상식: 제목 + 날짜의 리스트형 행 구성
- 견적 문의 밴드: 서브 배경(#F5F5F7) 라운드 24px 영역 + 필 입력창·버튼

### 3-5. 모바일 최적화

- 모바일 전용 레이아웃, 라이트 테마 동일 적용
- 상단에 직통 전화번호(010-8740-0440) 상시 노출. 시인성 확보를 위해 차콜 배경 바로 처리하며, 터치 시 즉시 전화 연결
- 시공 사례 카드는 1열, 신뢰 지표 스트립은 2열로 전환
- 히어로 헤드라인은 32px로 축소

### 3-6. 기타 공통 요구

- 홈페이지형 블로그 풀스킨 디자인 적용 (라이트 테마 기준)
- 위젯 연동: 전화걸기, 카카오톡 오픈채팅, 견적문의 폼
- 하단 푸터: 사업자정보 + 네이버 지도, 보조 텍스트 컬러(#6E6E73) 적용

## 5. 제작 범위 (v1.2 개정)

v1.2에서는 산출물을 2단계로 분리합니다. 네이버 블로그는 레이아웃 폭과 위젯 규격이 고정되어 있어 자유로운 조판이 불가능하므로, 디자인 확정용 프리뷰와 실제 스킨 적용을 나누어 진행합니다.

### 1단계 — 디자인 시안 프리뷰 (완료)

| 항목 | 내용 |
| --- | --- |
| 형태 | 독립 웹페이지 (PC + 모바일 반응형) |
| 목적 | 클라이언트 디자인 확정 및 검수용 |
| 포함 범위 | 메인 화면, 시공 사례, 주차장 상식, 상담 및 문의 4개 화면 |
| 비고 | 실제 동작하는 화면으로 검수 가능. 네이버 블로그에 그대로 적용되지는 않음 |

### 2단계 — 네이버 블로그 스킨 적용 (예정)

| 항목 | 내용 |
| --- | --- |
| 스킨 폭 | 네이버 블로그 기본 레이아웃 규격에 맞춰 재조정 |
| 타이틀 영역 | 승인된 히어로 디자인을 이미지로 제작 후 링크 영역 지정 |
| 위젯 | 전화걸기, 카카오톡, 견적문의 버튼을 위젯 규격에 맞춰 제작 |
| 게시물 | 시공 사례·주차장 상식 게시물 템플릿 제작 |
| 기본 세팅 | 프로필 이미지, 블로그 닉네임, SEO 세팅(태그, 설명 등) |
| 푸터 | 사업자정보 + 네이버 지도 삽입 |
| 모바일 | 모바일 커버 최적화, 번호 터치 시 즉시 연결 |

### 추가 요청 가능 항목 (별도 협의)

- 시공 사례 게시물 카드 템플릿 추가 제작
- 초기 게시물 5~10건 샘플 작성 지원

## 6. 전달 및 검수 사항

- 제작 후: PC·모바일 동시 검수, 라이트 배경 위 현장 사진 노출 상태 확인
