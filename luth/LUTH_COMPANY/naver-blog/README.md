# 네이버 블로그 적용 가이드

루쓰컴퍼니 주차차단기 블로그 — 요구사항정의서 v1.2(라이트 테마) 기준 산출물입니다.

`src/`의 Next.js 사이트는 디자인 확정을 위한 **시안 프리뷰**이고, 이 폴더는 그 디자인을 **실제 네이버 블로그에 옮기는 파일**입니다.

## 이미지와 위젯을 왜 나눴나

네이버 블로그는 웹사이트처럼 조판할 수 없습니다. 쓸 수 있는 자리가 두 종류뿐이고 성격이 정반대입니다.

| | 이미지 | HTML 위젯 |
| --- | --- | --- |
| 자리 | 타이틀, 프로필 | 사이드바 (폭 170px 고정, 높이 600px 이하) |
| 디자인 | 자유롭게 만들 수 있음 | 인라인 스타일만, 좁고 투박함 |
| 클릭 | **안 됨** | **됨** |

그래서 **보여줄 것은 이미지로, 누를 것은 위젯으로** 갈랐습니다.

타이틀 이미지에는 버튼을 일부러 그리지 않았습니다. 그림 위의 버튼은 눌리지 않는데 방문자는 눌러 보게 되고, 반응이 없으면 그냥 나가버립니다. 전화·카카오톡·견적문의는 전부 위젯이 맡습니다.

같은 이유로 위젯도 이미지가 아닌 HTML로 만들었습니다. 이미지 위젯은 전화번호가 바뀔 때마다 다시 그려야 하고, 모바일에서 번호를 눌러 바로 걸 수 없습니다.

## 폴더 구성

```
naver-blog/
├── README.md              이 문서
├── images/                업로드용 완성 이미지  ← 그대로 올리면 됨
│   ├── title-966x600.png
│   └── profile-161x161.png
├── widgets/               위젯직접등록용 HTML  ← 그대로 붙여넣으면 됨
│   ├── widget-cta.html
│   ├── widget-trust.html
│   └── widget-company.html
├── post/                  게시물 본문 템플릿
│   ├── index.html
│   ├── post.css
│   └── post.js
└── css/
    └── naver-blog.css     디자인 토큰 원본 (참조용)
```

이미지는 `scripts/build_naver_images.py`가 굽습니다. 문구나 로고를 바꿨다면 아래를 다시 실행하세요.

```bash
python scripts/build_naver_images.py
```

## 1단계. 이미지 올리기

### 타이틀 — `images/title-966x600.png`

**관리 › 꾸미기 설정 › 스킨 선택 / 타이틀 꾸미기**

1. 타이틀에서 **직접등록**을 고르고 이미지를 올립니다.
2. **영역 높이를 600으로** 맞춥니다. 이보다 낮추면 아래쪽 전화번호가 잘립니다.
3. **블로그 제목 표시를 해제**합니다. 켜두면 이미지 위에 제목 글자가 겹칩니다.

배경에 현장 사진을 깔고 싶으면 `naver-blog/images/source/` 폴더를 만들고 사진 한 장을 넣은 뒤 스크립트를 다시 실행하세요. 왼쪽은 글자가 읽히도록 희게 덮고 오른쪽에만 사진이 비칩니다. 사진이 너무 어두워 문구가 묻히면 스크립트가 대비를 계산해 막아 세우고 알려줍니다.

### 프로필 — `images/profile-161x161.png`

**관리 › 기본 설정 › 기본 정보 관리 › 블로그 정보**

'블로그 프로필 이미지'에 등록합니다. PC에서는 사각형, 모바일과 댓글에서는 원형으로 잘려 나오는데 로고를 원 안쪽에 넣어 두었으니 어느 쪽에서도 잘리지 않습니다.

## 2단계. 위젯 등록하기

**관리 › 꾸미기 설정 › 레이아웃·위젯 설정 › 위젯직접등록**

레이아웃은 **사이드바가 있는 유형**을 골라야 합니다. 1단 레이아웃에서는 위젯이 보이지 않습니다.

| 파일 | 위젯명 | 역할 |
| --- | --- | --- |
| `widgets/widget-cta.html` | 상담문의 | 전화 · 카카오톡 · 견적문의 3버튼 + 대표번호 |
| `widgets/widget-trust.html` | 회사강점 | 전국 직영 시공 등 신뢰 지표 4항목 |
| `widgets/widget-company.html` | 사업자정보 | 사업자정보 + 네이버 지도 링크 |

각 파일에서 맨 위 주석(`<!-- -->`)을 뺀 나머지 전체를 위젯코드입력란에 붙여넣습니다.

지도는 위젯 안에 넣을 수 없어 링크로 처리했습니다. 실제 지도를 보여주려면 네이버 기본 위젯인 **지도**를 함께 추가하세요.

### 등록 전에 채워야 할 값

붙여넣기 전에 아래 자리를 실제 값으로 바꿔야 합니다. 그대로 두면 방문자에게 노출됩니다.

| 파일 | 바꿀 자리 | 넣을 값 |
| --- | --- | --- |
| `widget-cta.html` | `KAKAO_URL` | 카카오톡 오픈채팅 주소 |
| `widget-cta.html` | `INQUIRY_URL` | 견적 문의 게시글 주소 |
| `widget-company.html` | `[대표자명]` | 대표자 성명 |
| `widget-company.html` | `[000-00-00000]` | 사업자등록번호 |

사업자정보는 표기 의무가 있으니 빈칸으로 두고 공개하지 마세요.

## 3단계. 게시물 쓰기

스마트에디터 ONE에는 HTML 직접 입력이 없어서, 브라우저에서 서식째 복사해 붙여넣는 방식으로 만들었습니다.

1. `post/index.html`을 브라우저로 엽니다.
2. 시공 사례 또는 주차장 상식 템플릿의 **서식째 복사**를 누릅니다.
3. 블로그 글쓰기 화면에 붙여넣고 대괄호 자리를 채웁니다.

붙여넣은 뒤 색이나 여백이 조금 달라질 수 있습니다. 한 번 다듬은 글을 스마트에디터의 **내 템플릿**으로 저장해 두고 이후에는 그것을 불러 쓰는 편이 가장 안정적입니다.

## 4단계. 마무리 세팅

- **카테고리**: 시공 사례(빌라·오피스텔 / 상가·빌딩 / 주차 유료화·무인화), 주차장 상식(자가정비·팁 / 법규·설치 기준), 상담 및 문의(간편 견적 문의 / 공지사항)
- **SEO**: 블로그 설명에 "주차차단기", "차량번호인식기", "LPR", "주차장 설치" 포함. 게시물마다 태그 5개 이상
- **모바일**: PC 타이틀과 위젯은 모바일 앱에 나오지 않습니다. 앱의 **홈 편집 › 이미지 변경**에서 커버를 따로 지정해야 톤이 맞습니다

## 검수 항목

- [ ] 타이틀이 PC에서 잘리지 않는가 (영역 높이 600)
- [ ] 타이틀 위에 블로그 제목 글자가 겹치지 않는가
- [ ] 프로필이 모바일에서 원형으로 잘려도 로고가 온전한가
- [ ] 위젯 3개가 사이드바에 나오는가
- [ ] 전화번호를 모바일에서 누르면 바로 걸리는가
- [ ] 카카오톡·견적문의 링크가 실제 주소로 바뀌었는가
- [ ] 대표자명과 사업자등록번호가 채워졌는가
- [ ] 게시물 템플릿의 표와 구분선이 모바일에서 깨지지 않는가

## 디자인 토큰

수정이 필요하면 `css/naver-blog.css`의 값을 먼저 바꾸고, 각 HTML 파일의 인라인 스타일과 `scripts/build_naver_images.py`의 상수에 반영하세요.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| background | `#FFFFFF` | 메인 배경 |
| foreground | `#1D1D1F` | 본문 텍스트, 주요 CTA 배경 |
| gray-bg | `#F5F5F7` | 섹션 밴드 배경 |
| gray-card | `#FBFBFD` | 카드 배경 |
| gray-text | `#6E6E73` | 보조 텍스트 |
| gray-line | `#D2D2D7` | 헤어라인 구분선 |

버튼 라운드는 980px, 카드 라운드는 18px입니다.
