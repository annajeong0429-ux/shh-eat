# Shh-eat

Shh-eat은 Codex 연습용으로 진행한 오피스 스낵 브랜드 랜딩 페이지 프로젝트입니다.

회의, 화상통화, 조용한 사무실에서도 티 나지 않게 먹을 수 있는 저소음 간식 경험을 중심으로 아이디어를 정리하고, 브랜드 방향과 웹 페이지까지 확장해 보았습니다.

## 작업 흐름

아이디어 -> 프로젝트 -> 문서 -> GitHub -> 리서치 -> 웹(Vercel)

## 진행 메모

이 프로젝트는 유튜버 woozoobro 콘텐츠를 보면서 Codex 사용 흐름을 연습하기 위해 만들었습니다.

브랜드 기획, 문서화, 리서치, GitHub 커밋, Vercel 배포까지 한 번의 작은 프로젝트 흐름으로 경험해 보는 것이 목적입니다.

## 배포

Vercel을 통해 Shh-eat 랜딩 페이지를 배포했습니다.

- 웹 링크: https://shh-eat-nu.vercel.app
